# Carry · coach de prácticas de golf

App web instalable (PWA) para entrenar en la cancha con Toptracer: plan de sesiones adaptado al hándicap con 98 ejercicios (incluidos los de Tiger Woods, Phil Mickelson, Luke Donald, Dave Pelz o Seve), registro de bolas, rondas reales y virtuales, partidas en Stableford, medal o match play con 27 campos, y un hándicap de juego (HCP CARRY) calculado con el método WHS.

- **Usar:** abre https://jorge-grube.github.io/carry/ en Safari → Compartir → «Añadir a pantalla de inicio».
- **Datos:** se guardan solo en el dispositivo (localStorage). Copia de seguridad desde Bolsa → «Guardar copia en Archivos».
- **Sin servidor ni dependencias:** `index.html` lleva todo el código; `sw.js` permite usarla sin conexión.

Instrucciones detalladas en [LEEME.md](LEEME.md).
